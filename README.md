# Helf Coming Soon

Static, responsive Coming Soon page based on the provided Figma design.

## Files
- `index.html` — page markup
- `styles.css` — responsive styles
- `assets/HelfLogo.svg` — provided Helf logo

## Deploy
Upload the entire folder contents to your website's public/web root.

Examples:
- cPanel: upload contents into `public_html`
- Nginx/Apache: point the site root to this directory
- Vercel/Netlify: deploy this folder as a static site

No build step is required.

## Font
The page loads Sora 400/600 from Google Fonts. If your production environment blocks external fonts, self-host Sora and replace the Google Fonts links with local `@font-face` rules.
